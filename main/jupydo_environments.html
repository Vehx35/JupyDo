GPU requests

DateUserEnvironmentWhen / whyStatusGPU

The environment does not start until you approve and choose its GPU; the user gets a message and starts it. No turns are enforced (users agree among themselves, e.g. with Bookings), and the job queue keeps using every GPU. Take back: the environment keeps the GPU until it is reset or deleted.

Environments per user

How many environments each user may have (default ; 0 = no limit).

UserEnvironmentsMaximum

Stop: the environment stops, as when its user stops it (container and files kept). Delete: the environment and its container are removed, as when its user deletes it; the user's files in /sharedFolder are kept, software installed with sudo is lost. Empty fields stay unchanged. CPU and RAM apply immediately, also to running environments, and stay after restarts. Disk = /sharedFolder of the user (plus the old work volume, if not yet migrated), measured every hour; users over their limit get an urgent notification until they are back under it. Reset (stopped environments only): fresh container at the next start, files in /sharedFolder are kept.
