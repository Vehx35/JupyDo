# Apptainer in JupyDo

`apptainer_tutorial.ipynb` shows how to use Apptainer (formerly Singularity) inside a JupyDo
environment: running containers from Docker Hub and BioContainers, keeping images as `.sif`
files in `/sharedFolder`, containers of the other architecture (sandbox folders) and Apptainer
in the job queue.

It needs an environment created with the **Apptainer** option (Optional modules), on an image
of the same architecture as the server.
