# Job queue examples

- `jobqueue_python.ipynb`: the `%%job` magic with Python
- `jobqueue_R.ipynb`: the same with R
- `jobqueue_gpu.ipynb`: GPU jobs (nvidia-smi, then a PyTorch benchmark)

Open one, run the cells in order. Results are written in `results/` next to the notebooks.
This folder is a copy for you: change or delete it as you like.
