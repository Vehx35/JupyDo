Commit (save as image)

Download

Exports the current state of this environment as one .zip in /sharedFolder/exports/: the image, run.sh (Linux/macOS) and run.cmd (Windows) to start it with JupyterLab on any computer with Docker, and a README. Your files in /sharedFolder are not included.

Environments larger than GB need an admin's approval: the request is sent automatically.
